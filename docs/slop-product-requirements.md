# Slop Product Requirements

The [canonical Slop PRD](https://docs.google.com/document/d/1on3Ge018mShloCpxVMs62ZCA81YA1U3HUv2s-VV7cWo/edit) is maintained in Google Docs.
It contains the product requirements, MVP delivery packages, acceptance checks,
open decisions, issue coverage, and completion record. There is no separate
MVP plan. Do not maintain another requirements copy in this repository.

Read the PRD before selecting or reviewing work. Cite its requirement ID and
MVP package ID in each implementation PR. If access fails, request access from
a maintainer. Do not infer scope from an issue or an old document.

## Change control

Maintainers approve scope and policy changes in the canonical PRD before
implementation. An issue, model recommendation, or draft PR is not approval.
Keep requirement IDs, decision owners, approval links, and effective dates.
Historical requirements remain in Git history. They do not override the current
PRD. Operational guides explain implementation; they do not expand product scope.
